Privacy

The Marginalia Corpus needs nothing about you. There is no account and nothing to sign in to.

The connector. Your question and the names you ask about are matched against a static file and then dropped; they are not stored or logged. For each call we send one event to PostHog with three things: which tool ran, whether it worked, and how long it took. No IP address, no user agent, no account, nothing that identifies you or your words.

This website. We count visits with Vercel Web Analytics and PostHog: pages viewed, the copy button, and whether a visit came from the connector (src=mcp in the link).

The data. The corpus is a static file built from public scholarly archives (credited on the connect page). The connector does not call those archives and sends them nothing.

Questions: open an issue at github.com/2016judea/marginalia-corpus/issues.

Built once from eight public scholarly archives and served as a static file. Text is quoted only where the archive's own terms allow it, with the citation it asks for. No images from any archive are served or linked.
